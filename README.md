# StarFinder

Campers will explore the world of generative AI and the underlying technology behind this powerful trend. Throughout the week, campers will be working with the latest generative AI models and constructing their own muti-modal personal assistant while deconstructing the foundational topics such as Training Sets, LLMs, Transformers, APIs, Supervised Learning, Unsupervised Learning, and much more. By the end of this cutting-edge camp, campers will use powerful programming languages such as Python and Java Script to harness the power of modern AI models.

Final Project: Based off the business model/idea created, build your own website using the AI tools and prompts explored during this 5-day AI Engineering Basics: Introduction To LLMS summer camp.
